# Перевірка Front-end 1.1

Дата: 02.10.2026. Середовище перевірки: Linux, Python 3.12, Flask/Waitress зі встановленого requirements-lock.txt, Playwright 1.62.1 та Chromium. Це результат перевірки в середовищі розробки, а не твердження про вже виконаний запуск оновлення на Mac користувача.

## Фактичний результат

- **46 pytest-тестів пройдено**, 9,11 с: 43 наявні перевірки backend і 3 нові перевірки HTML-оболонки, доступу до статичних файлів та політики безпеки. Закриті API та runtime-файли не стали публічними.
- **25 браузерних перевірок пройдено** зі справжніми HTTP-запитами до Waitress і тимчасовою SQLite. Повний перелік — `frontend-e2e-results.json`.
- Вхід/401; порожній список; тема після перезавантаження; створення наряду; валідація/422; створення та прив’язка клієнта; підтвердження готовності; CSRF-renewal після явної відмови; збереження приміток без скидання готовності; блокування незбережених змін; фото; запуск і завершення; захист від дублікатів; картка авто та успадкування клієнта; скасування; конфлікт видалення/409; резервна копія; OCR; контрольована відмова OCR/503; повільний запит; мережева помилка та повторення GET; завершення сесії.
- Ширини 1200, 736, 390 і 320 px у світлій та темній темах без горизонтального переповнення. Окремо перевірено детальну картку на 320 px.
- Помилок виконання JavaScript під час сценаріїв не виявлено.

Фікстура запускає окремий сервер на вільному loopback-порту, створює тимчасового оператора й видаляє тестові дані після завершення. Власні `instance/` та обліковий запис користувача не використовуються. Мережеві відмови, перший CSRF-reject і OCR/503 у відповідних сценаріях імітуються маршрутизацією Playwright; основні операції виконуються реальним API. OCR також викликано без підміни на синтетичному зображенні номера. Це не оцінка точності на реальних автомобілях.

## Повторення перевірок

Звичайному користувачеві Node.js не потрібний. Для розробника, після встановлення Python-залежностей і створення .venv:

```bash
.venv/bin/python -m pytest -q
npm ci
npx playwright install chromium
npm run test:frontend
```

На Windows перша команда: `.\.venv\Scripts\python.exe -m pytest -q`. Browser runner автоматично вибирає Python з .venv. Для іншого інтерпретатора задайте `APEX_PYTHON` повним шляхом. На Linux для браузера можуть знадобитися системні залежності Playwright. Знімки екрана та results.json створюються в `frontend-test-results/`, цей каталог виключено з Git.

## Що ще перевірити перед пілотом на СТО

Запуск нової версії на конкретному Mac/Windows, Safari та інших цільових браузерах; якість OCR на реальних фото; довготривале використання, доступність із допоміжними технологіями, великий обсяг даних, процедура відновлення копій на цільовому комп’ютері. Синтетичні браузерні сценарії не замінюють перевірки приймальником.
